# Sofia Pro

Положите сюда лицензированные файлы шрифта Sofía Pro:

- `SofiaPro-Regular.woff2` (400)
- `SofiaPro-Medium.woff2` (500)
- `SofiaPro-SemiBold.woff2` (600)
- `SofiaPro-Bold.woff2` (700)

Опционально те же имена с расширением `.woff`.

После добавления файлов обновите страницу — шрифт подхватится автоматически.

## PDF

Для PDF-отчёта уже подключены бесплатные шрифты с кириллицей:

- `NotoSans-Regular.ttf`
- `NotoSans-Bold.ttf`
